# Start from actual evidence

1. Load `system/agent/documents.md` for intake/source retention and `system/agent/data.md` before maintaining career records. Reuse the selected résumé and existing state; read the actual accessible contents, not only a path/preview. If no input exists, ask whether to use an existing résumé or start from scratch.
2. Retain exact originals or honest text-only evidence/context under `system/userinfo/main/source/`, with stable IDs, original names, access/coverage and the notes source inventory. Context-only intake creates no résumé facts/TeX/PDF; before a legitimate master exists retain sources/notes without a fake identity. Gather actual missing experience conversationally; chat-only discovery writes nothing.
3. Once the actual intake boundary is met, maintain complete facts-only v3 at `system/userinfo/main/facts.json`; author `main/main.tex` directly. Keep all supported facts in the master, faithful rewrites in TeX and context-only sources discoverable without inventing claims. Apply full-content/evidence/readable-layout protections.
4. For authorized first build/export/preview, load `system/agent/rendering.md`. Missing tools stop affected output, not intake; no installation is implied. Offer optional local Git only after the first working résumé, using `system/agent/git.md` if accepted.

**Gotcha:** The shipped empty preview can be fresh. Personalized TeX/history or other career state with a missing master is damaged/partial work: preserve it, never reset it to the preview.

**Return:** Useful intake progress, actual editable/durable links when produced, and precise unresolved evidence or output blockers—not a setup interview or design bank.
