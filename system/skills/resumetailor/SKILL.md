# Tailor independent applications

1. Load `system/agent/applications.md` for allocation/context and `system/agent/documents.md` for evidence/full-content protections. Bind each company, role and actual JD independently; ask one pairing question only when ambiguity changes the action. Comparison-only requests create nothing.
2. Reuse only an identified application; otherwise allocate a collision-safe application directory. Preserve supplied display labels/unknowns in context.md. Retain actual JD original bytes or honest text-only source and readable job.md, binding exact paths/access/coverage through applications.md; no placeholder JD.
3. Author that directory's main.tex with `../../../resume-style.tex`. Use supported career evidence and relevant retained person context; preserve all skills/items/results unless scoped selection permits otherwise. JDs/research/context cannot invent experience. Never change master/siblings merely to tailor or inherit another document's history/review.
4. Load `system/agent/rendering.md` for each authorized build/preview/export. Fix wasted layout and tighten wording faithfully before resolving a real content/length conflict; no shrinking or hidden cuts.

**Return:** Each company/role binding, its own actual source/PDF links and limits. Tailoring never authorizes login, prefilling, sending, uploads or submission; Git remains separately scoped under `system/agent/git.md`.
