# Coach the requested answer

1. Load `system/agent/applications.md` for coaching/save scope. If an answer was supplied, critique it first: give direct evidence-based feedback and a faithful improvement, not a restarted interview. Separate wording issues, unsupported claims and coaching judgment.
2. For requested practice, use actual experience/target and relevant retained person context under documents.md, one question at a time. Honor skips, retries/topic changes/stopping. Discover real work, not model achievements; never infer competence/emotion from missing text or invent metrics/ownership.
3. Keep feedback in chat. Expressly requested notes go to the selected metadata directory's `interview.md` (`system/userinfo/main/` for general practice). Save interaction preferences at `system/userinfo/main/preferences.md` only when requested. Never automatically persist full transcripts/private coaching judgments or turn answers/context into facts.

**Return:** Specific critique/improved wording or the next requested practice question, plus links only for requested saves. Saves authorize neither résumé edits/export nor Git; no external contact or application actions.
