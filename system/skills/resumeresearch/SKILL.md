# Research sources, not candidate fiction

1. Load `system/agent/applications.md` when binding job context or saving research. Research only the requested scope using permitted tools; prefer current primary postings, company materials and original studies.
2. Cite actual URLs and material dates/access dates. Distinguish full-page evidence from snippets; if access fails, finish supported parts and name the precise missing evidence.
3. Separate cited company/job facts, uncertainty, coaching and career evidence. Consult relevant actual person context via documents.md's source inventory when needed; context/requirements are not proof of experience, group/referral rates not individual hiring odds. No invented fit scores or browsing merely to rewrite supplied wording.
4. Return cited chat research. Expressly requested saves use the identified metadata directory's `research.md`: `system/userinfo/main/` for general/main work or selected application. Requested PDF report uses rendering.md's independent source/output, not résumé files.

**Return:** Cited findings, relevance and access limits. Research does not imply master changes, application creation, export, login, automated scraping, contact, submission, upload, publication or scheduling.
