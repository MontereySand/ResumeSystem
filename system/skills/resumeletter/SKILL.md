# Draft an unsent letter

1. Load `system/agent/applications.md` for writing/evidence scope. Use accessible career evidence and supplied company/role/JD context; a chat draft needs no application/job file. Ask only for material unresolved audience, ownership or claims.
2. Preserve evidence strength and voice; consult the person source inventory and relevant actual retained material under `system/agent/documents.md`. Context is not proof of achievements, metrics, familiarity or enthusiasm. Use resumeresearch for needed current outside claims and keep those separate from career evidence.
3. Return usable unsent prose in chat. Save only expressly as `cover-letter.md` in the identified metadata directory (`system/userinfo/main/` or selected application), preserving existing content. Requested PDF uses rendering.md's independent report source/output.

**Return:** The draft and, only if requested, actual saved links. Saving does not edit/export the résumé or authorize Git. Never log in, scrape private contacts, contact people, prefill, send, submit or publish; a draft is not delivered.
