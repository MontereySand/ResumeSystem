## Coursework-Selection Rules

- Read this file and the target job description before editing the tailored resume.
- Match coursework explicitly requested or strongly signaled by the job description first.
- Select only 2–4 completed courses that directly support the target role; remove generic or irrelevant courses to preserve resume space.
- Prefer advanced courses in the candidate's degree area, then use relevant mathematics, communication, business, or domain courses when the job description supports them.
- Use the exact course code and official title from the table. Do not invent course descriptions, grades, completion status, or stronger-sounding course names.
- Exclude withdrawn, failed, zero-credit, and non-credit repeated attempts. List an in-progress course only when it is clearly labeled and materially useful.
- Prioritize courses from the degree-granting institution unless the job description or candidate explicitly calls for transfer coursework.
- General role signals: software roles favor object-oriented programming, data structures, algorithms, software engineering, systems, operating systems, and databases; data/ML roles favor data wrangling, statistics, probability, linear algebra, data mining, and machine learning; security/HCI roles favor security, ethics, human-centered design, and technical communication.
- Replace the tailored LaTeX `Coursework` line with the selected courses and document the choices and reasoning in the company's `current.md`.
- If this file has not been populated with a real transcript, ask the candidate to supply the course data instead of inferring it.
